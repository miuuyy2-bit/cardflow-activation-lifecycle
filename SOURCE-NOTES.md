## Dataset method

The JSON dataset is an editorial synthesis of the five-state model used on the page. Source IDs point only to the official claims each source supports. Empty `sourceIds` do not mean a state is universally defined; they mark a model boundary for which the project does not assert a source-specific protocol.

The dataset contains no card records, issuer feeds, balances, rates, user submissions or transaction outcomes. It is a vocabulary and evidence-boundary reference, not a status database.

## Deliberate exclusions

- The prepared draft's Vanilla-specific activation example is not used because the official help page returned an access error during the current verification pass.
- No universal point-of-sale protocol is claimed. Activation paths vary by issuer, product and sales channel.
- No legal conclusion is drawn from the CFPB source outside its stated U.S. scope.
- No current balance, acceptance, rate, recovery or refund outcome is promised.
